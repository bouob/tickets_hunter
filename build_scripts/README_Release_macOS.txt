================================================================================
                 Tickets Hunter - macOS 使用說明
================================================================================

本版本由 GitHub Actions 自動建置，未使用 Apple 付費開發者憑證簽署。
因此首次開啟時 macOS 會擋下來——這是 Gatekeeper 的預設行為，不代表檔案有問題。
下方「首次開啟」章節說明如何放行，「驗證來源」章節說明如何自行驗證這份檔案
確實是由公開原始碼建置而成。

================================================================================
                            首次開啟
================================================================================

1. 解壓縮 ZIP 檔案
   建議放到「應用程式」或家目錄底下的固定位置。

2. 解除隔離標記（必要，只需做一次）
   打開「終端機」，輸入 xattr -dr com.apple.quarantine 後面加一個空格，
   再把解壓縮出來的 tickets_hunter 資料夾拖進終端機視窗，按 Enter。

   完整指令長這樣：
     xattr -dr com.apple.quarantine ~/Downloads/tickets_hunter

   這一步是移除「從網路下載」的隔離標記。不做的話，每個執行檔第一次啟動
   都會被攔截。

3. 雙擊 start-settings.command
   會開啟終端機視窗並啟動設定介面，接著用瀏覽器開啟它印出的網址。

4. 設定完成後，雙擊 start-bot.command 開始搶票。

若略過步驟 2，也可以改用：系統設定 -> 隱私權與安全性 -> 找到被攔截的項目 ->
按「仍要打開」。macOS 15 之後，舊版「在 Finder 按右鍵選打開」的做法已失效。

================================================================================
                            驗證來源
================================================================================

每個 Release 都附帶 GitHub 簽發的建置證明（build provenance attestation），
記錄了這份檔案由哪個 commit、哪個 workflow、在哪台 runner 上建出來。
安裝 GitHub CLI 後可自行驗證：

  gh attestation verify tickets_hunter_macos_arm64_vXXXX.XX.XX.zip \
     --repo bouob/tickets_hunter

驗證通過，代表這份二進位檔確實出自公開原始碼的自動建置流程，
中間沒有任何人手動改過。

同一個 Release 內也附有 SHA256 檢查碼檔案，可用來比對下載完整性：

  shasum -a 256 -c SHA256SUMS-macos-arm64.txt

================================================================================
                          架構與已知限制
================================================================================

本版本僅提供 Apple Silicon（M 系列）建置，需要 macOS 13 Ventura 以上。
Intel Mac 不在支援範圍，請改用原始碼自行打包，方式見專案的 guide/macos.md。

已知限制：

  - 驗證碼自動辨識（OCR）已在 Apple Silicon 上實測通過。若個別活動辨識失敗，
    可改用手動輸入驗證碼。
  - 音效通知在 macOS 上可能不會發出聲音；Discord / Telegram 通知不受影響。
  - 程式會在需要時自動下載 Chrome for Testing，首次啟動可能較久。

回報問題：https://github.com/bouob/tickets_hunter/issues
